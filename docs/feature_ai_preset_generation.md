# AI-Powered Preset Generation

AI Wallgen includes an advanced feature that uses AI (Google's Gemini model) to automatically generate coherent and contextually appropriate setting presets. This allows users to quickly create a diverse range of starting points for their wallpaper generations, tailored to specific artistic styles.

## Overview

The AI Preset Generation system works by:
1.  Determining a **base artistic style**. This can be a style you input manually or one generated by the [AI Style Generator](./feature_ai_style_generation.md).
2.  **Categorizing** this base style using an extensive internal catalog (`ai_prest_gen.style_category_catalog`).
3.  Fetching a **structural template** and **AI instructions** specific to that category.
4.  Instructing the Gemini AI to **fill out the template** with detailed settings (camera, lighting, composition, colors, etc.) that are appropriate for the base style and category.
5.  Validating, refining, and saving the AI-generated preset for your use.

Key Modules Involved:
-   `ai_prest_gen.ai_preset_generator`: The main script and orchestrator for this feature.
-   `ai_prest_gen.style_category_catalog`: Contains the logic and data for categorizing styles and providing AI instructions.
-   `ai_prest_gen.style_templates` (and its sub-modules like `photographic_style_templates.py`): Provides the JSON structure (template) that the AI fills.
-   `ai_prest_gen.camera_settings`: Dynamically generates realistic camera settings for many templates.
-   `wall_gen.settings_modules.preset_management`: Handles the saving and storage of the generated presets.

## How It Works in Detail

1.  **Initiation & Base Style:**
    -   You can run the AI preset generator via its command-line interface (e.g., `python ai_preset_generator.py generate --style "oil painting"`).
    -   If no style is provided, it can prompt you to enter one or even use the AI Style Generator to create a novel base style.

2.  **Style Categorization:**
    -   The input `base_style` (e.g., "Impressionistic Landscape Photography") is processed by the `categorize_style` function within `ai_preset_generator.py`.
    -   This function uses the comprehensive data in `ai_prest_gen.style_category_catalog.py` (which includes keyword matching, hybrid style definitions, and a priority order) to map the input style to a known internal category (e.g., "photographic", "oil_painting", "cyberpunk_portrait").

3.  **Template and Instruction Retrieval:**
    -   Based on the determined `style_category`, the system fetches two key pieces of information:
        -   **JSON Template:** From `ai_prest_gen.style_templates.get_template_for_category`. This function acts as a dispatcher, calling specific template providers (e.g., `get_photographic_template` from `photographic_style_templates.py`). The template defines the structure of `imagen_settings` (including nested dictionaries for camera, lighting, color, etc.) that the AI needs to populate. Many templates also incorporate dynamically generated camera settings via `ai_prest_gen.camera_settings.get_dynamic_camera_settings` for realism.
        -   **AI Instructions:** From `ai_prest_gen.style_category_catalog.instructions_for_category`. These are natural language instructions tailored to the category, guiding the AI on what kind of settings to generate (e.g., for "noir_photography", it might emphasize "Monochrome, deep shadows, moody lighting").

4.  **Prompting Gemini AI:**
    -   A detailed prompt is constructed for the Gemini model. This prompt includes:
        -   The base style name.
        -   The determined style category.
        -   The category-specific instructions.
        -   The JSON template structure that Gemini must fill.
        -   Explicit instructions to create a unique `preset_name`, `description`, choose a `mood`, and generate appropriate `negative_prompt` and `style_negative_prompt` values.
        -   A critical instruction is to fill *all* fields from the template with specific, fitting values and not leave defaults unchanged unless truly appropriate.

5.  **AI Response and Processing:**
    -   The Gemini model (typically a capable version like `gemini-2.5-flash-preview-04-17` as seen in `ai_preset_generator.py`) processes the request and returns a JSON string containing the filled-out preset.
    -   The script parses this JSON. It then validates the structure, merges the AI's suggestions with the original template to ensure completeness, and refines certain fields (e.g., ensuring `moods` is a list with one item).
    -   For certain traditional art styles, `camera_settings` might be explicitly removed.

6.  **Uniqueness Check & Saving:**
    -   The generated preset is hashed and checked against a local cache (`generated_presets_cache.json`) to avoid duplicates.
    -   If unique, the user is shown a preview and asked to confirm saving.
    -   Upon confirmation, the preset is saved using the `save_preset` function from `wall_gen.settings_modules.preset_management`. This typically involves:
        -   Saving the JSON data to a file in the `presets/` directory (e.g., `impressionistic_dream_1627882822.json`).
        -   Adding it to the TinyDB database for presets (managed by `preset_management_tinydb.py`).
    -   The system attempts retries if a unique preset isn't generated initially.

## Using the AI Preset Generator (CLI)

The `README.md` provides a good starting point for CLI usage. Key commands include:

-   **Generate a preset for a specific style category:**
    ```bash
    python ai_preset_generator.py generate --style photographic
    python ai_preset_generator.py generate --style "oil painting"
    ```
    (You can also run `python ai_preset_generator.py` and choose options from the interactive menu.)

-   **Directly generate for a custom style name:**
    ```bash
    python ai_preset_generator.py --style "Mystical Forest Concept Art"
    ```

The generated presets can then be loaded and used within the main AI Wallgen application to guide your image creations.

## Benefits

-   **Rapid Preset Creation:** Quickly generate a variety of starting points.
-   **Coherent Settings:** The AI aims to create settings where camera, lighting, color, etc., all work together harmoniously for the given style.
-   **Discovery:** Explore new combinations of settings you might not have thought of.
-   **Customization Base:** Use AI-generated presets as a foundation and then fine-tune them to your exact liking.

This AI-driven preset generation significantly enhances the creative workflow within AI Wallgen, making it easier to achieve desired artistic outcomes.
