# AI Preset Generator Guide

## Overview

The AI Preset Generator is a powerful feature in Wallgen that leverages advanced AI technology to create customized presets for wallpaper generation. It simplifies the process of generating unique and creative presets by automating the configuration based on user inputs and AI-driven algorithms. This feature enhances user experience by providing intelligent suggestions and reducing manual setup time.

This guide will walk you through the functionality, usage, and best practices for the AI Preset Generator.

## Step-by-Step Instructions

This section describes how to generate AI presets using the Wallgen application.

### Generating AI Presets via UI

1. Launch the Wallgen application.
2. Navigate to the "Advanced Options" menu.
3. Select "Generate AI Preset" from the list.
4. Choose "Generate New AI Preset" to start the AI generation process.
5. Wait for the AI to generate a coherent preset based on Gemini AI.
6. Upon success, the preset will be applied to your user preferences automatically.
7. You can save the generated preset for future use via the "Manage Presets" menu.
8. If the AI generation fails, you can choose to generate a random fallback preset.
9. Use the preview feature to view wallpapers generated with the new preset.

### Generating AI Presets via CLI

- Use the command line option `--ai-preset` to generate and apply an AI preset directly.
- The preset will be generated using Gemini AI and applied to your preferences.
- If the AI generation fails, a fallback random preset will be applied.
- You can save or manage presets using the interactive menus after generation.

This step-by-step guide helps users efficiently create AI-generated presets tailored to their preferences.

## Gemini AI Integration

The AI Preset Generator uses Google's Gemini AI to create intelligent and coherent wallpaper presets. Gemini AI generates a JSON-formatted preset that includes genres, styles, moods, and detailed image generation settings such as camera, lighting, composition, and color parameters.

The generation process involves sending a carefully crafted prompt to Gemini AI, requesting a set of artistically compatible settings. The AI attempts up to three times to produce a unique preset that has not been generated before, using a caching mechanism to avoid duplicates.

If the AI fails to generate a unique preset, a fallback random style mix preset is created.

The JSON structure generated by Gemini AI includes:

This integration provides users with creative and unique presets generated by advanced AI technology.

## Preset Caching Mechanism

To ensure uniqueness and avoid repetition, the AI Preset Generator uses a caching mechanism that stores hashes of previously generated presets.

- When a new preset is generated, its JSON content is hashed using MD5.
- The hash is compared against a cache of recent preset hashes stored in a JSON file (`generated_presets_cache.json`).
- If the hash is found in the cache, the preset is considered a duplicate and discarded.
- The AI attempts up to three times to generate a unique preset.
- Successfully generated presets have their hashes added to the cache.
- The cache maintains only the last 50 preset hashes to limit file size.

This mechanism helps maintain diversity in generated presets and improves user experience by reducing repeated results.

## Fallback Mechanisms

If the AI Preset Generator fails to produce a unique or valid preset after multiple attempts, it falls back to generating a random style mix preset.

The fallback preset is created by randomly selecting genres, styles (usually a mix of 2-3 compatible styles), moods, and other image settings with default or random values.

This ensures that users always receive a usable preset, even if the AI generation encounters issues.

The fallback mechanism maintains artistic coherence by using predefined style categories and sensible default settings.

Users can then customize or save the fallback preset as desired.

This approach guarantees continuous usability and a smooth user experience.

## Tips for Best Results

To get the most out of the AI Preset Generator, consider the following tips:

- Ensure your Gemini API key is correctly configured in the environment or config file.
- Use clear and descriptive prompts when generating presets to guide the AI effectively.
- Experiment with mixed style presets for richer and more unique artistic effects.
- Save generated presets you like for easy reuse and further customization.
- Use the fallback random preset as a starting point if AI generation does not meet your expectations.
- Regularly update Wallgen and its dependencies to benefit from improvements in AI generation.
- Customize advanced settings after generation to fine-tune the output to your preferences.
- Review and adjust negative prompts to avoid unwanted image artifacts.
- Use the preview feature to evaluate presets before applying them as wallpapers.

Following these tips will help you create high-quality, personalized wallpaper presets using AI.

## Integration with Other Features

The AI Preset Generator integrates seamlessly with other Wallgen features to provide a cohesive user experience:

- **Preset Management:** Generated AI presets can be saved, loaded, and deleted using the preset management interface. This allows users to reuse and customize AI-generated presets.
- **Advanced Settings:** AI presets update user preferences including advanced image generation settings such as camera, lighting, composition, and color parameters.
- **Command Line Interface:** Users can generate AI presets directly via CLI options, enabling automation and scripting.
- **Fallback Mechanisms:** When AI generation fails, fallback presets ensure continuous usability.
- **Preview Feature:** Users can preview wallpapers generated with AI presets before applying them.
- **Logging and Error Handling:** The system logs AI generation events and errors for troubleshooting and improvement.

This integration ensures that AI-generated presets are fully supported across the application, enhancing flexibility and user control.
