# Preset Management Guide

This guide explains how to use the preset management system to save, load, and manage your wallpaper generation settings.

## Table of Contents
- [Overview](#overview)
- [Managing Presets](#managing-presets)
- [Best Practices](#best-practices)
- [Troubleshooting](#troubleshooting)

## Overview

The preset management system allows you to:
- Save your current settings as named presets
- Load presets with options to merge or replace settings
- View detailed information about your presets
- Track which preset is currently active
- Safely delete presets with automatic backups

## Managing Presets

### Accessing Preset Management
1. From the main menu, select "Tools & Utilities"
2. Choose "Manage Presets"

### Saving a Preset
1. Configure your settings as desired
2. Go to preset management
3. Select "Save Current Settings as Preset"
4. Enter a name for your preset
5. Confirm if you want to overwrite an existing preset

### Loading a Preset
1. Go to preset management
2. Select "Load Preset"
3. Choose a preset from the list
4. Select how to apply the preset:
   - **Replace**: Completely replace current settings with preset
   - **Merge**: Update only the settings defined in the preset

### Viewing Preset Details
1. Go to preset management
2. Select "View Current Preset Details"
3. You'll see:
   - Metadata (creation date, description)
   - Imagen settings
   - Wallpaper settings

### Deleting a Preset
1. Go to preset management
2. Select "Delete Preset"
3. Choose the preset to delete
4. Confirm deletion
   - A backup is automatically created
   - Backup is kept for 24 hours

## Best Practices

### Naming Conventions
- Use descriptive names that indicate the purpose
- Include key settings in the name (e.g., "nature_8k_dreamy")
- Avoid special characters

### Organization
- Regularly review and clean up unused presets
- Keep backups of important presets
- Document complex preset configurations

### Settings Management
- Start with a base preset for similar wallpapers
- Use merge option to combine different aspects
- Test presets before deleting old versions

## Troubleshooting

### Common Issues

**Preset Not Saving**
- Check write permissions
- Ensure valid preset name
- Verify enough disk space

**Settings Not Applying**
- Check if all required settings exist
- Try replace instead of merge
- Verify preset file integrity

**Preset File Missing**
- Check presets directory
- Look for .bak backup files
- Verify file permissions

### Data Recovery
- Check for .bak files in presets directory
- Restore from backup within 24 hours
- Use file recovery tools if needed

## Tips and Tricks

1. **Quick Workflow**
   - Save different presets for different styles
   - Use merge to combine best aspects
   - Keep commonly used settings in base presets

2. **Advanced Usage**

3. **Maintenance**
